# Elevora Consulting
*A responsive consulting website*

## Project Overview
Elevora Consulting is a clean, responsive website concept for a consulting company. It is designed to present the company professionally and make it easy for visitors to explore the site and contact the team.

## Key Features
- Responsive layout for desktop and mobile
- Light and dark display modes
- Contact form
- Mobile-friendly navigation

## Run Locally
1. Open the project folder in Visual Studio Code.
2. Open `index.html` with the Live Server extension.
